# Project skills

The skills in this directory are vendored from
[mattpocock/skills](https://github.com/mattpocock/skills)
(commit `c55ee46`, plugin version 1.2.3, MIT, see `LICENSE.mattpocock-skills`).
Only the skills listed in that repo's `.claude-plugin/plugin.json` are included;
the `misc/`, `in-progress/` and `deprecated/` buckets are left out.

Run `/setup-matt-pocock-skills` once to configure the issue tracker, triage
labels and docs location for this repo.

To update, re-copy the skill folders from a newer checkout of the upstream repo.
